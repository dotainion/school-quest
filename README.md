Project Overview

The platform is designed to support collaborative learning between students and teachers by enabling them to ask and answer questions, share knowledge, and engage in academic competitions. The goal is to improve learning outcomes and increase overall pass rates through active participation and motivation.

In addition to individual engagement, the platform introduces a structured competition system where students can compete with one another to encourage consistent learning and improvement. It also includes inter-school competitions, allowing schools to compete on performance metrics and academic participation. This fosters a healthy competitive environment that encourages excellence across all participating schools.

Core Features
Public Features

Home Page – Overview of the platform, featured schools, and recent questions
About Page – Explanation of how the platform works
Schools Leaderboard – Ranking of schools based on performance points
Questions Feed – Browse all posted questions
Question Details Page – View questions and their answers
School Profile Page – Public profile for each school
Student Profile Page – Public profile for each student
Login Page
Register Page
Student Features
Student Dashboard – Overview of personal activity and performance
Ask Question Page – Submit new questions
My Questions Page – View questions posted by the student
My Answers Page – View answers provided by the student
Notifications Page – Updates and alerts
Achievements / Badges Page – Rewards and milestones
Edit Profile Page – Manage personal information
School Competition Features
School Dashboard – School performance statistics and ranking
School Members Page – List of students per school
School Challenges Page – Active inter-school competitions
Challenge Details Page – Progress, participants, and scoring
School vs School Results Page – Historical competition results
Admin Features
Admin Dashboard – System overview and controls
Manage Users – Add, edit, or remove users
Manage Schools – Maintain school records
Moderate Questions & Answers – Content moderation
Manage Competitions – Control challenges and events
Reports & Analytics – Platform insights and performance tracking
